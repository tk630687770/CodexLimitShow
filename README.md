# CodexLimitShow

Windows 10/11 桌面悬浮组件：本机单进程 WPF 界面，通过 Codex CLI 的 `app-server --stdio` 显示配额。

## 使用

- 折叠态为双圈：内圈 5 小时，外圈为周额度（无周额度时显示月额度），中心分别显示两项剩余百分比；顶部套餐字样采用浅紫色玻璃内雕效果。无活动窗口显示空轨道和“—”，不推断为 100%。
- 单击双圈展开详情；双击强制核对账号并刷新额度。面板高度随内容调整，正常屏幕不显示滚动条；仅在屏幕可用高度不足时保留滚动以免裁掉信息。点击左上角的向内收拢图标或组件外收起，返回展开前的双圈或停靠条及原位置。
- 重置机会集中在一张玻璃卡片内：次数与已知最早到期时间常驻，点击“查看明细”显示按到期时间排序的完整列表；“使用重置”位于卡片内。展开／收起明细同步调整整个面板高度，刷新保留展开状态；移至另一块屏幕或缩放变化后重新核对可用高度。获得时间和原始类型保留在明细悬停提示中。
- 拖拽双圈，圆心越过屏幕边缘时预览平直玻璃条；松手停靠。上下边为三行横条（套餐、5h、7d／月），左右边为窄竖条（套餐在上、7d／月靠屏幕边缘、5h 靠内侧），均显示独立进度和剩余百分比。展开面板替换折叠视图，历史快照在面板侧边显示。
- 详情标题栏或托盘菜单可打开 Codex Desktop；详情内还可固定位置、打开只读历史、缩至托盘、退出。打开 Codex、升级、有效期核验和使用重置在操作返回前显示进度反馈；打开 Codex 会等到检测到桌面窗口或超时。额度每 30 秒读取一次；账号资料仅首次、登录文件变化及强制核对时读取；token 活动统计仅启动或跨日读取。
- 点击“托盘”后，悬浮组件隐藏，任务栏通知区旁显示横排烟晶卡片 `5h xx% · 7d xx%`（无周额度时改为月），不显示进度条。悬停提示前两行分别显示 5 小时与 7d／月的剩余百分比及本地时间的额度重置日期，下方保留数据更新时间和操作提示；未提供重置日期时标明未知，不推断时间。单击卡片在附近弹出详情，卡片继续显示；点击外部、详情收起按钮或“托盘”只关闭临时详情，历史及确认弹层获得焦点时不会误收起。双击卡片恢复原来的面板／双圈／停靠状态及位置，右键打开菜单；单击会等待系统双击间隔，避免双击时误弹详情。卡片复用 30 秒额度数据，不增加网络请求；详情和卡片同步更新，隐藏期间停止双圈与升级提醒动画，每 2 秒仅在本地检查任务栏位置。空间不足或布局不可识别时保留／恢复悬浮组件，不遮盖系统按钮。目前只在主屏水平任务栏显示，竖向任务栏安全回退。未向 Explorer 注入代码或修改系统文件。
- 订阅日期优先显示当前账号登录凭据中自带的订阅截止声明，并标为“本地记录·待核验”；它不是令牌自身的过期时间，也不等于刚刚联网核验成功。仅首次识别／账号变化、用户点“手动刷新有效期”、已存日期与当前套餐矛盾时尝试联网核验。非公开 ChatGPT 接口可能被 Cloudflare 网页防护以 HTML 403 拦截，此时保留本地日期或上次核验值并显示原因，不读取浏览器 Cookie 绕过防护。
- “使用重置”要求当前账号、新鲜额度、可用机会和用户二次确认。调用官方 App Server `account/rateLimitResetCredit/consume`，只传一次性幂等键，不传 credit ID。结果不确定时本次运行不再发起新的消费。**构建和验证期间没有实际消费机会。**
- 详情顶部改为 Codex 标志、向上箭头＋托线的升级图标与图钉三个按钮，升级不再使用容易被认作刷新的环形箭头；悬停显示含义，操作期间显示等待指示。收起使用向内收拢图标；固定后图钉高亮。升级默认每 24 小时自动检查一次公开 GitHub 最新正式 Release 元数据，保存上次尝试时间，重启不重复检查，失败不高频重试；通过 ETag 条件请求与压缩减少流量，不后台下载 EXE。发现新版本后升级图标柔和呼吸并显示小圆点；仅在面板可见时播放，收起、托盘隐藏或操作中停止，系统关闭动画时使用静态提示。点击升级可立即检查，仍需用户确认后才下载，下方显示真实下载进度，悬停及状态行显示阶段和百分比；随后校验 SHA-256 和版本，旧进程退出后原位替换并重启。若服务器未提供文件长度，则显示不定进度条。日常 30 秒额度刷新不检查更新；程序所在目录需允许当前用户写入。

## 隐私与限制

只在订阅有效期核验时短暂读取本机 `.codex/auth.json` 中当前账号的令牌，并仅向 `chatgpt.com` 请求账号绑定的订阅信息。令牌、cookie、完整内部账号 ID、credit ID 和原始服务端 JSON 都不会写入日志或历史。历史快照保存用户要求显示的完整邮箱、套餐、筛选后的配额和订阅日期，路径为 `%LOCALAPPDATA%\CodexLimitShow\snapshots.json`。不要把该文件或 `backups` 目录公开分发。

没有主动切号、后台服务、数据库或开机自启。双圈、停靠玻璃条使用 WPF 透明窗口与矢量绘制，不依赖实时桌面模糊。订阅接口并非公开稳定 API，不保证所有账号或网络环境可用。

## 构建与验证

需要 .NET 9 SDK：

```powershell
dotnet build
dotnet run -- --self-test
dotnet run -- --probe
dotnet run -- --probe-subscription
dotnet run -- --render-preview
dotnet run -- --taskbar-test
```

`--probe` 仅输出配额百分比和机会数量；`--probe-subscription` 仅输出本地时间日期或安全错误类型；`--render-preview` 生成玻璃双圈、停靠玻璃条、面板和任务栏卡片的预览 PNG，同时检查明细展开／收起的高度恢复、刷新状态保留、空列表、超过屏幕高度后的滚动、图标按钮进度与新版提示动画的启停行为。`--taskbar-test` 使用合成数据短暂显示自己的任务栏子窗，验证原生嵌入、尺寸、重建、状态恢复，并保存 `taskbar-live.png` 和 `taskbar-test.txt`；不重启 Explorer、不修改系统任务栏。预览和任务栏测试不联网，均不消费重置机会。

生成自包含单文件发布候选（项目根目录执行）：

```powershell
.\tools\Publish-CodexLimitShow.ps1
```

先递增 `.csproj` 中的版本号，再运行脚本。它会构建、自测并生成 `release/CodexLimitShow.exe`，只用于上传对应版本的 GitHub 正式 Release，不自动安装或上传。GitHub Release 标签、程序版本和 SHA-256 必须匹配。既有 `release/versions/`、`release/packages/`、`正式版/`、`dist/` 仅作为历史内容保留，不参与新版升级。目标电脑不必单独安装 .NET，但需安装并登录 Codex Desktop。

其他电脑首次安装：从 [GitHub Releases](https://github.com/tk630687770/CodexLimitShow/releases) 下载最新正式版 `CodexLimitShow.exe`，放进当前用户有写权限的目录并运行；以后点击面板中的“升级”即可远程更新。1.x ZIP 版本需手动下载 2.x EXE 一次，旧升级器不能识别新的单文件发布格式。账户快照保存在本机，不随升级包传输；公开发布不要求其他电脑登录 GitHub。

## 源码与许可证

- `WpfMain.cs`、`GlassWidget.cs`、`RingGeometry.cs`：入口、玻璃界面和双圈几何
- `TaskbarQuotaWindow.cs`：任务栏内的横排剩余额度卡片
- `CodexAppServerClient.cs`：本地 App Server 客户端、数据筛选解析及重置调用
- `SubscriptionLookup.cs`：隔离的非公开订阅日期只读查询
- `SnapshotStore.cs`：各账号最后一次成功快照
- `ReleaseUpdater.cs`：GitHub 正式版检查、下载校验和原位更新
- 旧 WinForms 实现仅在本机备份中保留，不参与编译或公开仓库
