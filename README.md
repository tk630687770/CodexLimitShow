# CodexLimitShow

Windows 10/11 桌面悬浮组件：本机单进程 WPF 界面，通过 Codex CLI 的 `app-server --stdio` 显示配额。

## 使用

- 从 2.7.1 起，本次检查版本若已确认直连失败并使用备用线路，随后的下载直接沿用备用，避免重复等待直连超时；下载进度与校验阶段持续标明 `GitHub`／`备用线路`。线路选择只影响本次进程中的已成功检查，不永久保存；下次检查仍优先直连，连接恢复后自动恢复直连下载。不增加检查或下载重试次数。
- 从 2.7.0 起，检查更新及下载 EXE 优先直连 GitHub；网络超时、403/408/429/5xx 或下载连接中断时，仅重试一次固定备用线路 `https://gh-proxy.org/`，界面提示正在切换。连接阶段每条线路最多等待 8 秒，下载连续 30 秒无数据视为失败，整体下载最多 10 分钟。仍每 24 小时只检查一次，失败不高频重试，确认前不下载。中转版本信息必须通过程序内置公钥的 ECDSA P-256 签名校验；文件仍核对官方资产 SHA-256、产品与文件版本。签名或文件校验失败停止升级，不降级为不安全安装；本地磁盘错误不触发换线路。第三方只能看到公开仓库请求，不传递 GitHub、Codex 或 ChatGPT 凭据。服务不保证长期可用；说明见 [GH-Proxy 文档](https://gh-proxy.com/docs/github-accelerator)。无法直连的旧客户端须先从其他电脑手动复制一次 2.7.0 或更高版本，且远程目标 Release 必须附有有效签名。
- 启动默认进入托盘模式，在任务栏通知区旁显示额度卡片，不先弹出桌面双圈；无安全空位时保留普通托盘图标。双击卡片或备用图标可恢复双圈，单击卡片查看临时详情。托盘详情展开／收起重置明细及刷新时保持靠任务栏的一侧固定：底部任务栏的面板向上展开、从顶部向下收起，不留下悬空间隙；顶部任务栏则固定面板顶部。仅内容超过屏幕可用高度时显示滚动条。
- 折叠态为双圈：内圈 5 小时，外圈为周额度（无周额度时显示月额度），中心分别显示两项剩余百分比；顶部套餐字样采用浅紫色玻璃内雕效果。无活动窗口显示空轨道和“—”，不推断为 100%。
- 单击双圈展开详情；双击强制核对账号并刷新额度。面板高度随内容调整，正常屏幕不显示滚动条；仅在屏幕可用高度不足时保留滚动以免裁掉信息。点击左上角的向内收拢图标或组件外收起，返回展开前的双圈或停靠条及原位置。
- 重置机会集中在一张玻璃卡片内：次数与已知最早到期时间常驻，点击“查看明细”显示按到期时间排序的完整列表；“使用重置”位于卡片内。展开／收起明细同步调整整个面板高度，刷新保留展开状态；移至另一块屏幕或缩放变化后重新核对可用高度。获得时间和原始类型保留在明细悬停提示中。
- 拖拽双圈，圆心越过屏幕边缘时预览平直玻璃条；松手停靠。上下边为三行横条（套餐、5h、7d／月），左右边为窄竖条（套餐在上、7d／月靠屏幕边缘、5h 靠内侧），均显示独立进度和剩余百分比。展开面板替换折叠视图，历史快照在面板侧边显示。
- 详情标题栏或托盘菜单可打开 Codex Desktop；详情内还可固定位置、打开只读历史、缩至托盘、退出。打开 Codex、升级、有效期核验和使用重置在操作返回前显示进度反馈；打开 Codex 会等到检测到桌面窗口或超时。额度每 30 秒读取一次；账号资料仅首次、登录文件变化及强制核对时读取；token 活动统计仅启动或跨日读取。
- 点击“托盘”后，悬浮组件隐藏，任务栏通知区旁显示横排烟晶卡片 `5h xx% · 7d xx%`（无周额度时改为月），不显示进度条。悬停提示共四行：5h 剩余百分比及重置时间、7d／月剩余百分比及重置时间、订阅到期时间、数据更新时间；日期按本地时间显示，缺日期标明未知或未核验，订阅沿用面板的本地记录／核验状态标签，不触发额外联网。操作说明移至右键菜单，仅在功能项旁以较小字号标注“单击”“双击”，不另加标题或右键提示。单击卡片在附近弹出详情，卡片继续显示；点击外部、详情收起按钮或“托盘”只关闭临时详情，历史及确认弹层获得焦点时不会误收起。双击卡片恢复原来的面板／双圈／停靠状态及位置，右键打开菜单；单击会等待系统双击间隔，避免双击时误弹详情。卡片复用 30 秒额度数据，不增加网络请求；详情和卡片同步更新，隐藏期间停止双圈与升级提醒动画，每 2 秒仅在本地检查任务栏位置。初次进入或运行中空间不足、布局识别失败时都保持托盘模式，暂时显示普通托盘图标，并改为每 10 秒重试；安全空位恢复后只恢复额度条，不自动弹回桌面，也不遮盖系统按钮。备用图标可双击或通过菜单手动恢复原来的组件状态；无额度条时隐藏“展开详情”菜单。用户主动打开的临时详情、历史及确认弹层不受布局失败影响。目前只在主屏水平任务栏显示，竖向任务栏使用普通托盘图标等待。未向 Explorer 注入代码或修改系统文件。
- 订阅日期保留当前账号最后一次核验结果；没有核验结果时显示登录凭据自带的订阅截止声明，并标为“本地记录·待核验”，不将其冒充联网查询。首次识别、同账号登录文件变化或强制核对时同步更新的本地声明，但不让同一天的登录声明覆盖网页核验精度。点击“网页核验有效期”使用独立持久化网页登录会话，正常登录并读取可见日期；已核验结果同步保存在账号快照中。尚无网页记录时，首次识别／切号或套餐矛盾检查仍可尝试原非公开接口，收到 401／403 即停止，不强刷凭据、不导出 Cookie。已有网页记录不再自动尝试该接口；日常 30 秒刷新不打开网页，也不增加订阅请求。切号、登录文件变化或新核验开始后，旧请求结果与错误均不能覆盖当前状态。
- “使用重置”要求当前账号、新鲜额度、可用机会和用户二次确认。调用官方 App Server `account/rateLimitResetCredit/consume`，只传一次性幂等键，不传 credit ID。结果不确定时本次运行不再发起新的消费。**构建和验证期间没有实际消费机会。**
- 详情顶部改为 Codex 标志、向上箭头＋托线的升级图标与图钉三个按钮，升级不再使用容易被认作刷新的环形箭头；悬停显示含义，操作期间显示等待指示。收起使用向内收拢图标；固定后图钉高亮。升级默认每 24 小时自动检查一次公开 GitHub 最新正式 Release 元数据，保存上次尝试时间，重启不重复检查，失败不高频重试；通过 ETag 条件请求与压缩减少流量，不后台下载 EXE。发现新版本后升级图标柔和呼吸并显示小圆点；仅在面板可见时播放，收起、托盘隐藏或操作中停止，系统关闭动画时使用静态提示。点击升级可立即检查，仍需用户确认后才下载，下方显示真实下载进度，悬停及状态行显示阶段和百分比；随后校验 SHA-256 和版本，旧进程退出后原位替换并重启。若服务器未提供文件长度，则显示不定进度条。日常 30 秒额度刷新不检查更新；程序所在目录需允许当前用户写入。

## 隐私与限制

### 网页核验订阅有效期（2.6.0）

展开面板点击“网页核验有效期”。首次在独立网页窗口亲自登录 ChatGPT／完成网站验证；之后复用固定的本机会话，不因关闭组件、重启或升级主动退出，但无法承诺网站会话有效天数。网页核验在读取日期前后各核对一次账户页邮箱，写入前再次通过 App Server 核对 Codex 当前账号和登录文件代次；不一致、切号、页面变化、关闭窗口或读取失败均不写入新日期。只接受账单页可见套餐说明中的唯一有效日期，不获取私有接口响应、Cookie、令牌或付款资料。支持当前中英文页面，布局或文案变化可能使读取失败。

成功后面板、任务栏悬浮提示和只读历史同步显示“网页核验”；网页只提供日期时不伪造时分，并保留“已取消续订”状态。结果和精度保存在原账号快照中，旧快照仍可读取。已有网页核验记录不会在启动时再尝试被拦截的订阅接口；30 秒额度刷新不打开网页、不发订阅请求。需要更新日期时由用户主动打开网页核验。

网页登录数据由 WebView2 保存在 `%LOCALAPPDATA%\CodexLimitShow\SubscriptionBrowserProbe`，复用已验证的独立工具会话，不复制 Edge 或 Codex 凭据，也不随单 EXE 升级删除。组件仍为单 EXE，但这项可选功能需要微软 WebView2 Runtime；缺失时仅网页核验不可用，额度显示继续工作，不自动安装 Runtime。使用前关闭独立验证工具，避免共用会话时互相干扰。用户应只进行核验，不在完整网页中更改订阅或付款设置。

只在订阅有效期核验时短暂读取本机 `.codex/auth.json` 中当前账号的令牌，并仅向 `chatgpt.com` 请求账号绑定的订阅信息。令牌、cookie、完整内部账号 ID、credit ID 和原始服务端 JSON 都不会写入日志或历史。历史快照保存用户要求显示的完整邮箱、套餐、筛选后的配额和订阅日期，路径为 `%LOCALAPPDATA%\CodexLimitShow\snapshots.json`。不要把该文件或 `backups` 目录公开分发。

没有主动切号、后台服务、数据库或开机自启。双圈、停靠玻璃条使用 WPF 透明窗口与矢量绘制，不依赖实时桌面模糊。订阅接口并非公开稳定 API，不保证所有账号或网络环境可用。

## 构建与验证

需要 .NET 9 SDK：

```powershell
dotnet build
dotnet run -- --self-test
dotnet run -- --probe
dotnet run -- --probe-subscription
dotnet run -- --diagnose-subscription
dotnet run -- --check-web-subscription
dotnet run -- --render-preview
dotnet run -- --taskbar-test
```

`--probe` 仅输出配额百分比和机会数量；`--probe-subscription` 仅输出本地时区的联网查询日期或安全错误类型；`--diagnose-subscription` 仅在显式运行时额外输出 HTTP 状态码、白名单内容类型、`cf-mitigated: challenge` 是否存在，以及白名单最终域名／接口类别。它不保存诊断文件，不输出请求参数、账号标识、令牌、Cookie、任意响应头或正文；收到 401／403 后不再尝试备用订阅接口，也不刷新凭据。普通日常刷新不输出这些诊断信息。`--render-preview` 生成玻璃双圈、停靠玻璃条、面板和任务栏卡片的预览 PNG，同时检查明细展开／收起的高度恢复、刷新状态保留、空列表、超过屏幕高度后的滚动、图标按钮进度与新版提示动画的启停行为。`--self-test` 包含布局连续失败时保留请求、减慢重试及停止后的取消检查。`--taskbar-test` 使用合成数据短暂显示自己的任务栏子窗，验证原生嵌入、尺寸、重建、模拟布局失败时不弹回桌面、额度条恢复、故障期间手动恢复及原状态保留，并保存 `taskbar-live.png` 和 `taskbar-test.txt`；不重启 Explorer、不修改系统任务栏。预览和任务栏测试不联网，均不消费重置机会。

连接尚未收到 HTTP 响应时，诊断入口只输出 .NET 标准连接错误类别和可选状态码，不输出异常消息、代理地址或内部异常内容。

`--check-web-subscription` 打开实际网页核验窗口，用当前 Codex 账号进行只读双重账号匹配和日期读取；只输出匹配成功与日期，不写入账号快照、不消费机会。未登录或需要网站验证时须由用户本人操作。独立验证工具位于 `tools/SubscriptionBrowserProbe`，不属于正式发布物。

生成自包含单文件发布候选（项目根目录执行）：

```powershell
.\tools\Publish-CodexLimitShow.ps1
```

先递增 `.csproj` 中的版本号，再运行脚本。它会构建、自测并生成 `release/CodexLimitShow.exe`，只用于上传对应版本的 GitHub 正式 Release，不自动安装或上传。GitHub Release 标签、程序版本和 SHA-256 必须匹配。既有 `release/versions/`、`release/packages/`、`正式版/`、`dist/` 仅作为历史内容保留，不参与新版升级。目标电脑不必单独安装 .NET，但需安装并登录 Codex Desktop。

从 2.7.0 起脚本同时生成 `release/release-signature.txt`：发布时须将该 HTML 注释原样追加到同版本 Release 的**说明正文**，仍仅上传单个 EXE。签名绑定仓库、版本和文件 SHA-256，不影响旧客户端直连升级，也不要求运行电脑携带密钥或额外文件。私钥位于原发布者 Windows 用户 CNG 密钥库 `CodexLimitShow.ReleaseSigning.v1`，不导出、不提交 Git；脚本会核对其公钥与程序内置公钥一致，缺失或不一致即停止。`tools/Initialize-ReleaseSigning.ps1` 仅用于初始建钥并输出公钥；本项目已初始化，切勿因换机器或用户而重建并擅自更换公钥。发布者用户密钥库丢失后，需要另行安排可信密钥迁移，旧客户端不会自动信任新密钥。

只读网络诊断可运行 `CodexLimitShow.exe --check-update-mirror`：从 2.7.1 起，同时模拟 GitHub API 和 EXE 直连失败，经真实备用线路获取元数据并验证内置公钥签名，再下载完整 EXE 并校验签名绑定的 SHA-256、产品和文件版本，随后删除临时下载，不执行或安装。此诊断会下载一次完整 EXE；不再要求直连 API 可达，远程版本必须有有效签名。诊断不改变系统代理或 VPN，不等同于另一台电脑的真实网络结果。

其他电脑首次安装：从 [GitHub Releases](https://github.com/tk630687770/CodexLimitShow/releases) 下载最新正式版 `CodexLimitShow.exe`，放进当前用户有写权限的目录并运行；以后点击面板中的“升级”即可远程更新。1.x ZIP 版本需手动下载 2.x EXE 一次，旧升级器不能识别新的单文件发布格式。账户快照保存在本机，不随升级包传输；公开发布不要求其他电脑登录 GitHub。

## 源码与许可证

- `WpfMain.cs`、`GlassWidget.cs`、`RingGeometry.cs`：入口、玻璃界面和双圈几何
